# 太空两相流 AI4S 实验平台 · 总体路线

> **定位**：本文是《热管理背景 AI4S 专项计划》的战略升级版——从"学习 + 地面文献复现"升级为"建设一个在轨两相流实验平台，用 AI 自主实验方法积累微重力两相流动数据"。前两份文档的方法学（代理模型、SHAP、贝叶斯优化、数字孪生）全部保留，成为本路线的地基阶段。
> **调研时间**：2026 年 10 月（设施状态以公开资料为准，上行渠道需实时核实）

---

## 一、为什么这件事值得做

微重力两相流的根本困境是**数据稀缺且机理不清**：重力的"掩盖效应"使地面实验难以分离浮力以外的力（剪切力、毛细力、表面张力），而机理不清直接导致工程模型不准——文献明确指出，常用地面关联式对微重力两相流压降的预测存在很大偏差，且"需要进行具有长期微重力环境的空间实验"[^116^]。FBCE 实验（Purdue + NASA Glenn，国际空间站）已经证明在轨两相数据库的巨大价值：一次在轨实验建立的微重力流动沸腾与 CHF 数据库，支撑了跨重力 ANN 预测等一系列 AI 工作[^98^]——**但全球范围内，这样的数据集一只手数得过来，而且都不是为 AI 时代设计的**（参数空间稀疏、测点少、无标准化元数据）。

更关键的是空白点：目前的在轨两相实验全部是"地面排程、人在回路"模式——地面定工况、上行指令、回传数据、地面分析、下一轮排期，一个循环以周计。**"AI 在轨自主设计实验"（active learning on orbit）在全球范围内几乎没有先例**（NASA 资助的微重力两相流型生成模型研究还停留在地面阶段[^103^]）。这意味着两件事：科学上，同样的在轨机时，自主实验可以数倍提高参数空间覆盖率；工程上，稀疏遥测带宽下只有"在轨做实验决策、只下行有价值的数据"才可持续。

你的位置恰好卡在三个交汇点上：热控系统工程（载荷的热设计是你的主场）、两相流学科（科学对象）、AI4S 方法学（实验范式）。这不是单点技能能启动的项目，但正是这种交叉让它难以被复制。

## 二、国际国内基线：平台思路已被验证，AI 自主化是空白

| 设施/项目 | 状态 | 对本项目的启示 |
|-|-|-|
| 中国空间站**两相系统实验柜**（梦天舱） | 在轨运行，国际首个专用空间两相系统大型实验平台；可更换实验模块（2024 年已由冷凝强化模块切换为沸腾换热模块）、多流量宽温域工质供给循环、多工位多参数协同观测[^108^][^112^] | 国家级平台存在 → 自建平台应错位：做它做不了的事（AI 自主决策、高通量参数扫描、标准化 AI 数据集） |
| 中国空间站**变重力实验柜** | 在轨，0–2G 连续可调；已开展月球/火星重力沸腾实验[^111^] | 重力作为连续自变量做实验——正是 AI 主动学习最喜欢的参数 |
| 流体物理实验柜（梦天舱） | 在轨，数字全息干涉、红外热像、PIV、LDV 等综合测试手段[^108^] | 光学诊断手段清单，可作为载荷传感设计的对标 |
| FBCE（ISS，美） | 2022 年在轨实验完成，大规模微重力流动沸腾数据库[^98^] | 数据库先例与格式对标；其数据已被 ANN 工作使用——说明"数据即论文" |
| 北京落塔 / IL-76 抛物线飞机（中科院国家微重力实验室谱系） | 国内微重力研究基础设施，已有两相流实验历史[^116^] | 地基验证的天然场所；落塔秒级、飞机 22 秒级微重力窗口 |
| 欧洲失重飞机（Novespace） | 经中科院空间应用中心失重实验中心可向中国用户提供抛物线飞行机会（40 人/2 吨设备/10–15 项实验，每次抛物线约 22 秒微重力）[^114^] | 中国团队的成熟先例：中科院太空制造团队 2016 年即通过此渠道完成微重力 3D 打印试验[^114^] |

**结论**：不要从零造一个"迷你两相柜"去和国家级平台正面竞争。正确姿势是：**以 AI 自主实验方法为核心增量**，先借现有设施（落塔、抛物线飞行、空间站合作模块）验证方法，同时并行研制具备边缘 AI 决策能力的自主实验载荷，走商业搭载或小卫星路线上行。

## 三、平台总体构想：天地一体三层架构

```
┌─────────────────────────────────────────────────┐
│ 天：自主实验载荷（Autonomous Experiment Payload）  │
│  · 两相实验回路（流动沸腾/冷凝/流型，可更换模块）    │
│  · 传感套件：压差/温度阵列/高速成像/空泡份额(电导/电容)│
│  · 边缘算力（抗辐照加固，跑压缩后的代理模型+主动学习）│
│  · 关键区别：实验设计由星上 AI 做，不是地面排程      │
├─────────────────────────────────────────────────┤
│ 地：数字孪生与训练中心                             │
│  · 高保真两相 CFD（VOF/两流体）批处理造数据        │
│  · 地面回路 + 落塔 + 抛物线飞行标定                │
│  · 跨重力统一模型（1g→10⁻⁶g 连续标度，对标 FBCE）   │
├─────────────────────────────────────────────────┤
│ 链：稀疏遥测下的实验科学闭环                       │
│  · 在轨：AI 选择下一个工况 → 执行 → 特征提取        │
│  · 下行：不吐原始数据，只吐特征+模型更新量           │
│  · 地面：模型重训练 → 模型压缩 → 上行更新           │
└─────────────────────────────────────────────────┘
```

这个架构里，**"链"是真正的技术壁垒**：它把上行带宽从瓶颈变成护城河——别人的载荷受限于下行原始数据，你的载荷下行的是"信息"。这也是论文和专利最集中的产出点。

## 四、五阶段路线

### P0 地基实验与方法复用（0–12 个月）

- 地面两相回路搭建（流动沸腾/冷凝可视段 + 温度/压差阵列 + 高速相机），优先复用你现成的水热试验能力
- 方法学直接继承 PHP 项目：批量工况扫描 → 代理模型 → SHAP → 主动学习选点；目标是把"AI 设计实验"流程在 1g 环境跑通
- 同时推进原 18 个月学习路径中的 AI 方法栈（它是本阶段的子集，不另起炉灶）
- **验收**：地面回路连续运行 ≥200 工况；主动学习比均匀网格用 1/3 工况达到同等模型精度（1g 环境下验证）

### P1 短微重力窗口的 AI 闭环（12–24 个月）——核心技术壁垒阶段

- 短微重力窗口是完美的"沙盒"：抛物线飞行单次 ~22 秒微重力、一次飞行 31 次抛物线[^114^]，落塔数秒级——窗口内必须自主决策，逼出真正的在轨 AI
- 载荷做成标准机箱（适配失重飞机和落塔吊篮接口），核心软件与未来的在轨载荷**同构**（边缘推理 + 主动学习控制器），只是算力和加固降级
- 实验范式：每个微重力窗口内，AI 根据实时传感特征选择下一工况（流量/功率/阀门动作），窗口间地面模型快速更新
- **渠道**：中科院空间应用中心失重实验中心（Novespace 中国代理）[^114^]；北京落塔（中科院力学所）
- **验收**：一次飞行完成 ≥30 个微重力窗口的自主工况序列；窗口内决策时延 < 1 s；成果形态：2–3 篇论文（方法学）+ 1 项软著/专利

### P2 在轨载荷工程（18–36 个月，与 P1 并行启动）

- 载荷定义：以 P1 机箱为基线，加三件套——抗辐照加固计算模块（边缘 AI 加速器）、工质回路密封与寿命设计（两相回路的密封与工质相容性是行业难题，需专项攻关）、热控设计（你的主场：废热排散、可变热导、热管网络）
- 关键设计约束前置：功耗预算、体积质量（对标立方星级载荷）、单向下行带宽预算驱动"在轨特征提取"设计
- 环境试验与可靠性：振动、热真空、EMC——这部分直接调用你的工程经验
- **验收**：载荷通过热真空与振动摸底；地面数字孪生（P0 的 CFD + 数据）对载荷首工况预测误差 ≤20%

### P3 上行与在轨运行（36–60 个月）

- **搭载渠道（按可行性排序，需实时核实征集状态）**：
  1. 中国空间站两相系统实验柜的合作实验模块（与总体单位联合申报，平台已有可更换模块机制[^112^]）
  2. 天舟货运飞船搭载 / 空间应用系统新技术试验渠道（中科院空间应用工程与技术中心为总体单位，常年组织征集[^109^]）
  3. 商业搭载：商业卫星平台预留载荷舱、力箭/快舟搭载余量、返回式卫星
  4. 国际合作渠道（两相系统实验柜首批项目已有 ESA 合作先例[^112^]）
- **在轨 AI4S 实验包**（三个递进实验）：
  1. 微重力两相流型主动测绘：AI 选择工况扫描流型图边界（对标和平号/FBCE 的流型数据库[^116^][^98^]，但用 1/5 机时）
  2. 跨重力连续标度：利用变重力设施或轨道机动间隙的重力变化，训练重力作为连续输入的统一关联式（呼应 FBCE-ANN 路线[^98^]）
  3. 烧干/CHF 边界主动逼近：安全约束下的主动学习，把 CHF 边界的测绘成本降低一个量级（对标清华微通道 CHF 工作[^82^]的微重力版）
- **验收**：在轨自主实验 ≥3 个月；公开数据集 + 基准发布（对标 PDEBench 的"微重力两相"版）

### P4 数据与模型生态（P3 启动后持续）

- 数据集：标准化元数据（工质/几何/重力水平/传感配置/不确定度），这是 FBCE 数据集没有做到的
- 基准：微重力两相流型识别 / CHF 预测 / 跨重力外推三个基准任务，吸引社区用你的数据
- 模型：跨重力统一关联式 + 流型生成模型（对标 NASA EPSCoR 方向[^103^]）+ 卫星热控数字孪生的直接应用

## 七、与原 18 个月计划的关系

原计划的第 0–12 个月（Python/ML/PINN/神经算子方法栈）**全部保留，并入 P0**；原计划的两个作品集项目（卫星热控数字孪生 toy model、微通道冷板 AI 设计工作流）转为 P0 的子任务；PHP 项目（已三阶段跑通）成为"代理模型 + 主动学习"方法学的预演，其阶段 3 的贝叶斯优化直接改写为 P1 的窗口内工况选择器。原计划第 12–18 月的"沸腾器件 CHF 预测器"作品集项目升级为 P1 的地面部分（烧干边界主动逼近的 1g 预研）。

**一句话总结**：原计划教你成为"懂 AI 的热控工程师"；本路线在此之上加一个目标——**让你的实验装置自己设计实验，并把它送上天**。
